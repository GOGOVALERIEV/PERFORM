# Approved study sources

Use sources that are legal to access and clear about their license.

## Books

- **OpenStax** — the default for modern foundational textbooks. Its books are free, peer-reviewed, and openly licensed. Use the official OpenStax site and retain the book URL and edition in the manifest.
- **Project Gutenberg** — use for classics and older public-domain works. Check the individual book's licensing statement because public-domain status can differ by country.
- **Internet Archive / Open Library** — use for lawful borrowing or previewing where available, not as a replacement for a source's lending restrictions.
- **Author/publisher open-access editions** — use when the publisher clearly offers the exact edition under an open or free-to-read license.

Never present a pirated mirror as a study source. For a copyrighted book the user owns, work from their uploaded copy or lawful access; quote only what is necessary for analysis.

## Research and data

Use this source order unless the task says otherwise:

1. Official documentation, datasets, filings, or APIs.
2. Original research papers and source data.
3. Established institutions and reputable industry publications.
4. GitHub repositories only for implementation, not for unsupported factual claims.

Before using a GitHub repository, check:

- license permits the intended use;
- recent maintenance and a reproducible setup;
- clear input, output, and dependency expectations;
- source terms, rate limits, and whether the collector is compatible with them.

Store a `source_url`, access date, license/terms note, and purpose in each research manifest.
