# Realm 03: Learning

Study, courses, skill building, English, copywriting.

## Scripts
- `append_study_doc.py` — Appends content to study documents
- `build_lessons_doc.py` — Builds lesson documentation
- `auto_scheduler.py` — Python job scheduler (if revived)
- `make_presentation.py` / `presentation.py` — Marp + python-pptx presentations
- `transcribe-course.py` — Transcribes course videos
- `transcribe_youtube_channels.py` — YouTube channel transcription
- `youtube_bulk_transcriber.py` — Bulk transcriber
- `youtube_transcript_io.py` — Transcript I/O
- `yt_transcript_selenium.py` — Selenium-based transcript scraper

## When to Use
When learning, taking courses, building skills, or studying.
