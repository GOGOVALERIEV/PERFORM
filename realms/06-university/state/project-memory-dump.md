## 3. ВРАГЪТЕ (карта на детекторите)

### Tier 1: РЕАЛНАТА система — StrikePlagiarism.com
- В **Blackboard на ЮЗУ** (disted.swu.bg), LTI интеграция
- КС1 = 5+ думи съвпадения (%), КС2 = 25+ думи (опасната)
- AI модул: AIPC 0-100%, BERT-класификатор, червени фрагменти
- **Само-признание в техните документи:** "висок AI + ниска сходство = най-вероятно false response"
- Manipulation alerts: кирилски/латински размяни, скрити символи — ВСИЧКИ се засичат
- Cross-Check: сравнява докладите в същия batch (Джордж vs Валерия!)
- База: всяка предадена работа в ЮЗУarchive + 35M научни източници (МОН договор 2022)
- **НИКога не тествай с тестов файл.** Никога не авто-предавай.

### Tier 2: plag.bg (безплатен, БГ, rehearsal judge)
- similarity + AI + преведен плагиат
- **Файловете НИКОГА не влизат в сравнителна база** (проверена клауза)
- Нашите резултати: similarity 1%, AI 32% "low risk"
- Използваме го за self-check преди предаване

### Tier 3: строгите комерсиални (нашият benchmark)
- **JustDone** — 95-98% на AI текст, безплатен без login, БГ работи. НАШИЯТ основен съдия. Но: шумен (±30 точки между сканирания на същия текст!), след ~5 скана иска signup
- **GPTZero** — 97% на drill, 1 advanced scan/акаунт, после paywall. Trial: 7 дни, карта, €18.99/мес след
- **ZeroGPT** — сляп за български (0-58-83% хаос). Canary само

**Измервателно правило: ЕДИН скан = нищо. 3+ скана = медиана. Текстове < 60 думи = няма вердикт.**

## 4. ЕКСПЕРИМЕНТАЛНАТА АБИЛИЦА (всичко, което тествахме)

Базов текст: pol-izbori (изборните системи), 440-670 думи, български.

| Вариант | Метод | JustDone | Урок |
|---|---|---|---|
| baseline | един LLM pass | 93-100% | проблемът е ПРОЦЕСАТ, не моделът |
| v1 преразказ framing | "преразкажи, не назубряй" | 96% | framing сам не работи — LLM re-smooths |
| v2 synonym shuffler | синоними | 91% | козметика |
| v3 punctuation | дребни грешки | 96% | сам не работи |
| v4 spoken→formalize | транскрипция → формализиране | 99% | формализирането re-smooths — НАЙ-ЛОШОТО |
| **v5 изолирани изречения** | всяко изречение отделна генерация, код сглобява | **71%** | **КЛЮЧОВИЯТ МЕХАНИЗЪМ: чупи document-level подписа** |
| v6 редуване на модели | 2 модела редуване по изречение | 72% | плато — всички LLM са еднакво гладки |
| v7 конкретност | абстрактно → конкретно | 74% | helper, не magic |
| **v8 микро-препис x1** | всяко изречение пренаписано отделно | **38%** | **ЗЛАТНАТА СРЕДА: 38% + четимо** |
| v9 микро-препис x2 | повторно | 20% ⚠️ | ЦЕЛТАТА, но граматиката се разпада — забранено |
| v10 микро-препис x3 | повторно | 73% | деградацията се трупа |
| v11 quality-gated | 3 кандидати + съдия + fallback | 73% | пази качеството, не подобрява процента |

### ДРУГИ НАУЧЕНИ ФАКТОВЕ
- Преразказаната версия на dry facts: 96% (paraphrase добавя smoothness!)
- Verbatim facts: 70% (по-ниско от paraphrase!)
- Сходство: решено навсякъде (KS2=0 на 20+ доклада)
- Реферат шум: 38% → 72% → 38% на СЪЩИЯ текст (V8, 3 скана). ±30 точки!
- Цитат-богат текст: 43% (V16)
- JustDone променя модела си: V8 = 38/38/72/38/82/38/73 на различни дни

### КЛЮЧОВИЯТ ЗАКОН
**Всяко изречение = едно гладко LLM поколение. Никое пренаписване не чупи ВЪТРЕШНОСТТА на изречението.** Решението: генерирай изреченията отделно, сглоби с КОД, никога не давай финален LLM pass върху цялото.

## 5. РЕЦЕПТАТА (текуща най-добра)

```
ФАКТИ (затворен кратък списък, 8-10, човешки подбрани)
  ↓
[1] ИЗОЛИРАНИ ИЗРЕЧЕНИЯ: 2+ различни модела, по 1-3 факта на повикване,
    темп 1.0-1.4, с КОНКРЕТНОСТ правило (всяко твърдение + име/дата/число),
    стилови вариации (кратко 6-12д / дълго 18-28д / "Ама..." / въпрос-отговор)
  ↓
[2] ГЕЙТ на всяко изречение: 5-gram среща бележката (никакви 5+ последователни
    думи), числа/имена запазени, няма слепени думи. FAIL → regenerate (x3) →
    fallback: оригиналната бележка
  ↓
[3] КОД сглобяване: разбъркан логически ред, пунктуационен jitter
    (2-3 запетаи махнати пред "че/да/което")
  ↓
[4] ЕДИН микро-препис pass: всяко изречение през различен модел,
    темп 1.0+ (V8 метода). Само ЕДИН pass — вторият разваля граматиката
  ↓
[5] ГЕЙТ пак: fact-diff (числата непроменени) + stylecheck
  ↓
[6] ТЕСТ: ksim (сходство) → JustDone x3 (медиана) → plag.bg upload
```

**Резултат на тази рецепта: 38% JustDone (медиана 38% от 12 скана), сходство 0%, граматика ОК (1 pass).**

**Следващата граница (неизпробвано):** преводачна верига (бг→фински→бг през OpenRouter), комбиниран с изолация. Научно най-силният механизм (DIPPER: детекция 70.3% → 4.6%).
